# Household budget tracker

Reads Danske Bank transaction-list PDFs, de-duplicates the transactions into SQLite,
categorizes them with Claude, and writes an HTML report of the last 12 months against
yearly limits per category. See `PRD.md` for the full spec.

## Setup

Requires Python 3.11+, [uv](https://docs.astral.sh/uv/), and [Claude Code](https://claude.com/claude-code)
logged in with your Claude subscription (run `claude` once and log in). Categorization runs
`claude -p`, so it counts against your subscription's usage limits — no API key is used.

```sh
uv sync
cp config.example.toml config.toml        # adjust categories and yearly limits
cp overrides.example.toml overrides.toml  # optional
mkdir -p statements
```

In Danske Bank netbank, export the transaction list ("Transaktioner") as PDF and put the
files in `./statements/`. Keep the default file name — it starts with the account number
(`3577517835_2025.10.12-2026.10.12.pdf`), which is used as the account id so overlapping
exports of the same account de-duplicate.

## Usage

```sh
uv run python -m budget run            # import + categorize + report (default)
uv run python -m budget import         # parse PDFs only
uv run python -m budget categorize     # categorize pending only
uv run python -m budget report         # regenerate report from DB
uv run python -m budget recategorize --all   # clear Claude results (keeps overrides) and redo
```

`--config` and `--overrides` select other files (defaults: `config.toml`, `overrides.toml`).
Then open `output/report.html`.

## Fixing a category

Add to `overrides.toml` and re-run:

```toml
[rules]                       # description substring, case-insensitive; first match wins
"REJSEKORT" = "Transport"

[transactions]                # fingerprint prefix as shown in the report (min. 8 chars)
"a3f9c1d2e4b5" = "Vacation"
```

Overrides are re-applied on every run; removing one sends the transaction back through
the cache/Claude.

## How it works

- **Parsing** (`budget/parser.py`): pdfplumber table extraction, with a text-line regex
  fallback for pages without a table. Rows that straddle a page break are rendered on both
  pages by the bank — they are merged back into one. After parsing, the running balance is
  checked row by row; a break is logged as a warning naming file and page.
- **De-duplication** (`budget/dedupe.py`): fingerprint is
  `sha256(account | date | amount | balance)`. The description is not part of it because
  the same transaction can come out with differently clipped text from two exports.
  Without a balance: `(account, date, description, amount, occurrence index)`.
- **Categorization** (`budget/categorizer.py`): overrides → merchant cache → Claude.
  Recurring merchants (same normalized description and direction) are sent once, 50 per
  request, with a JSON schema that restricts categories to the configured ones. Results
  with confidence ≥ 0.8 go into the merchant cache. Numbers of 6+ digits (account numbers)
  are masked before sending. If the API is unreachable, transactions stay uncategorized
  and show up under "Skal gennemses" in the report.
- **Budget** (`budget/budget_calc.py`): window is `(reference_date − window_months,
  reference_date]`; `spent = −sum(amount)` per category, so refunds reduce spending.
